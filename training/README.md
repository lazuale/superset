# Учебный стенд и данные

Вся первая версия курса использует **один небольшой учебный stack** и **один понятный набор данных**.

Ученик не устанавливает PostgreSQL отдельно. PostgreSQL запускается вместе с Superset через готовый `docker compose`-стенд курса.

## Таблица

```text
training.sales
```

## Поля

| Поле | Что означает |
|---|---|
| `sale_id` | номер строки продажи |
| `sale_date` | дата продажи |
| `region` | регион |
| `office` | офис |
| `manager` | менеджер |
| `product` | продукт |
| `quantity` | количество |
| `revenue` | выручка |
| `cost` | себестоимость |

## Требования к данным

Данные должны быть маленькими и понятными без дополнительной предметной области:

- несколько дат и минимум два месяца для работы с периодами;
- несколько регионов;
- несколько офисов;
- несколько менеджеров;
- несколько продуктов;
- повторяющиеся значения для группировки;
- числа, удобные для ручной проверки `SUM`, `COUNT`, `COUNT DISTINCT`, `AVG`;
- минимум один пример, позволяющий посчитать прибыль как `revenue - cost`;
- никаких искусственных сложностей, которые не нужны для базового курса.

## Файлы учебного стенда

При написании практической части здесь должны появиться:

```text
training/
├── README.md
├── compose.yaml
├── schema.sql
├── data.sql
└── check.sql
```

`compose.yaml` запускает готовый учебный stack Superset + PostgreSQL.

`schema.sql` создаёт внутри уже запущенного учебного PostgreSQL схему `training` и таблицу `sales`. Он не устанавливает сервер PostgreSQL и не требует отдельной настройки СУБД.

`data.sql` загружает фиксированный набор строк.

`check.sql` содержит контрольные запросы и ожидаемые итоги для сверки с Superset.

Урок 02 должен давать новичку готовые команды запуска, загрузки этих файлов, проверки данных и полного возврата стенда в исходное состояние.

До написания соответствующей практики пустые файлы не создаются.
