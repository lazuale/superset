# Учебные данные

Вся первая версия курса использует **один небольшой и понятный набор данных**.

## Таблица

```text
training.sales
```

## Поля

| Поле | Что означает |
|---|---|
| `sale_id` | номер строки продажи |
| `sale_date` | дата продажи |
| `region` | регион |
| `office` | офис |
| `manager` | менеджер |
| `product` | продукт |
| `quantity` | количество |
| `revenue` | выручка |
| `cost` | себестоимость |

## Требования к данным

Данные должны быть маленькими и понятными без дополнительной предметной области:

- несколько дат и минимум два месяца для работы с периодами;
- несколько регионов;
- несколько офисов;
- несколько менеджеров;
- несколько продуктов;
- повторяющиеся значения для группировки;
- числа, удобные для ручной проверки `SUM`, `COUNT`, `COUNT DISTINCT`, `AVG`;
- минимум один пример, позволяющий посчитать прибыль как `revenue - cost`;
- никаких искусственных сложностей, которые не нужны для базового курса.

## Файлы, которые появятся при написании практики

```text
training/
├── README.md
├── schema.sql
├── data.sql
└── check.sql
```

`schema.sql` создаёт учебную базу/схему и таблицу в том объёме, который нужен стенду.

`data.sql` загружает фиксированный набор строк.

`check.sql` содержит контрольные запросы и ожидаемые итоги для сверки с Superset.

Урок 02 должен давать новичку готовую команду загрузки этих файлов и простой полный сброс в исходное состояние.

До написания соответствующей практики пустые SQL-файлы не создаются.
