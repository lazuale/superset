# 07. Строим графики

**Статус:** зафиксирован план урока.

## Что научимся делать

Выбирать и строить несколько основных визуализаций.

## В урок входит

- когда нужна таблица;
- `Table`;
- `Big Number`;
- столбчатая диаграмма;
- временной график;
- выбор измерения и метрики;
- подписи и сортировка;
- сохранение `Chart`;
- несколько типичных ошибок выбора визуализации.

## После урока ученик должен уметь

Построить минимум три разных Chart на одном Dataset и понимать, какой вид графика подходит для простого вопроса.

## В урок не входит

Полный каталог chart plugins, карты, Handlebars, сложная кастомизация и расширенная аналитика.

## Практический результат

Сохранены несколько Chart, которые позже попадут в Dashboard.
