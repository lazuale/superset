# 08. Собираем Dashboard

**Статус:** зафиксирован план урока.

## Что научимся делать

Собирать несколько готовых Chart в одну рабочую панель, сохранять её и возвращаться к редактированию позже.

## В урок входит

- создание `Dashboard`;
- добавление сохранённых Chart;
- размещение и изменение размеров блоков;
- понятные названия;
- сохранение изменений;
- публикация панели;
- выход из Dashboard и поиск панели в общем списке;
- повторное открытие Dashboard;
- переход в режим редактирования, изменение расположения или размера Chart и повторное сохранение;
- базовый принцип: один Dashboard отвечает на конкретный набор вопросов.

## После урока ученик должен уметь

Самостоятельно собрать, сохранить, найти позже, снова открыть и изменить простую аналитическую панель.

## В урок не входит

Dashboard RBAC, embedding, CSS, темы оформления и сложная интерактивность.

## Практический результат

Есть опубликованный Dashboard из нескольких ранее созданных Chart, который ученик умеет повторно открыть и изменить.
