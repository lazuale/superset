# 08. Собираем Dashboard

Четыре Chart уже готовы. Теперь соберём из них одну рабочую панель и проверим, что Superset сохраняет не только сами графики, но и их расположение.

Dashboard будет называться:

```text
Учебные продажи
```

На нём должны оказаться:

```text
Продажи по регионам — таблица
Общая прибыль
Выручка по регионам — столбцы
Выручка по месяцам
```

Перед началом откройте `Charts` и убедитесь, что все четыре объекта действительно существуют и показывают правильные числа.

## Создаём панель

Откройте:

```text
Dashboards
```

Нажмите кнопку:

```text
Dashboard
```

Новый Dashboard откроется в режиме редактирования с заголовком:

```text
[ untitled dashboard ]
```

Замените его на:

```text
Учебные продажи
```

Справа будут две вкладки:

```text
Charts
Layout elements
```

На `Charts` находятся уже сохранённые графики. В `Layout elements` — дополнительные элементы компоновки вроде `Tabs`, `Row`, `Column`, `Header`, `Markdown` и `Divider`.

В этом уроке они пока не нужны. Нам важнее научиться нормально собрать панель из готовых Chart.

## Добавляем четыре графика

Перетащите на рабочую область:

```text
Общая прибыль
Выручка по регионам — столбцы
Выручка по месяцам
Продажи по регионам — таблица
```

Сразу проверьте, что данные не изменились после добавления на Dashboard.

Контроль:

```text
Общая прибыль = 1530.00

Север:
выручка = 1360.00
прибыль = 520.00

Юг:
выручка = 2645.00
прибыль = 1010.00

2026-01 = 1160.00
2026-02 = 1180.00
2026-03 = 1665.00
```

Если какой-то блок уже здесь показывает неправильное число, чинить его нужно в самом Chart через Explore. Размер и положение блока на Dashboard расчёт не меняют.

## Раскладываем панель

Для учебного примера используем простую схему:

```text
┌───────────────────────────────────────┐
│ Общая прибыль                         │
├───────────────────┬───────────────────┤
│ Выручка           │ Выручка           │
│ по регионам       │ по месяцам        │
├───────────────────┴───────────────────┤
│ Продажи по регионам — таблица         │
└───────────────────────────────────────┘
```

То есть KPI сверху, два сравнительных графика в центре и точная таблица внизу.

Перетащите блоки по сетке и подберите размеры так, чтобы всё читалось без перекрытий. Здесь нет задачи добиться идеального дизайна — нам нужно освоить сам механизм редактирования.

## Сохраняем и проверяем

Нажмите:

```text
Save
```

После обновления страницы расположение и размеры блоков должны сохраниться.

Теперь обратите внимание на статус Dashboard. Новый объект создаётся как:

```text
Draft
```

После проверки переключите его в:

```text
Published
```

`Published` означает статус внутри Superset. Это не делает панель публичной в Интернете и не отменяет существующие права доступа.

## Убедимся, что это действительно сохранённый объект

Вернитесь в список:

```text
Dashboards
```

Откройте `Учебные продажи` заново. Панель должна открыться в режиме просмотра с теми же четырьмя Chart.

Затем нажмите:

```text
Edit dashboard
```

Измените размер одного блока, например `Выручка по месяцам`, сохраните и снова откройте Dashboard из списка.

Если новое расположение осталось, механизм сохранения понятен.

## Что хранится где

Это место полезно зафиксировать один раз:

```text
Chart
→ запрос, Metrics, Dimensions, Filters, тип визуализации

Dashboard
→ какие Chart размещены, где они стоят и как выглядит панель
```

Поэтому изменение ширины блока не может изменить `SUM(revenue)`. Если цифра поменялась — причина не в сетке Dashboard.

## Если что-то пошло не так

Если нужного графика нет на вкладке `Charts`, вернитесь в общий список `Charts`: скорее всего, он не был сохранён в уроке 07.

Если после перезагрузки вернулась старая раскладка, изменения не были сохранены кнопкой `Save`.

Если Dashboard всё ещё имеет статус `Draft`, переключите его вручную в `Published`.

Если неверны сами числа, откройте соответствующий Chart и разберитесь с ним в Explore. Dashboard здесь только показывает уже существующий объект.

## Что должно остаться

В списке `Dashboards` должен быть:

```text
Учебные продажи
```

со статусом:

```text
Published
```

и четырьмя сохранёнными Chart. После повторного открытия должны сохраняться заголовок, состав панели, размеры и расположение блоков.

Этого достаточно для механики. Вопрос о том, **как проектировать действительно хороший Dashboard**, вынесен отдельно в [справочник по композиции](08a-dashboard-design.md).
