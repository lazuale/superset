# 08. Собираем Dashboard

## Результат урока

После урока должен существовать опубликованный Dashboard:

```text
Учебные продажи
```

На нём должны находиться четыре Chart из урока 07:

```text
Продажи по регионам — таблица
Общая прибыль
Выручка по регионам — столбцы
Выручка по месяцам
```

## Перед началом

Откройте верхний раздел:

```text
Charts
```

Проверьте наличие всех четырёх Chart.

Контрольные значения:

```text
Общая прибыль = 1530.00

Север:
выручка = 1360.00
прибыль = 520.00

Юг:
выручка = 2645.00
прибыль = 1010.00

2026-01 = 1160.00
2026-02 = 1180.00
2026-03 = 1665.00
```

## Создаём Dashboard

Откройте:

```text
Dashboards
```

Нажмите кнопку:

```text
Dashboard
```

Слева от подписи отображается значок `+`.

Откроется новый Dashboard с начальным заголовком:

```text
[ untitled dashboard ]
```

Новый Dashboard открывается в режиме редактирования.

Нажмите заголовок и замените его на:

```text
Учебные продажи
```

Подтвердите изменение заголовка.

## Панель конструктора

Справа в режиме редактирования находятся вкладки:

```text
Charts
Layout elements
```

В `Charts` отображаются сохранённые Chart, доступные для добавления на Dashboard.

В `Layout elements` находятся элементы компоновки:

```text
Tabs
Row
Column
Header
Markdown
Divider
```

Для этого урока используем только сохранённые Chart и обычную сетку Dashboard.

## Добавляем Chart

На вкладке:

```text
Charts
```

по очереди найдите и перетащите на рабочую область:

```text
Общая прибыль
Выручка по регионам — столбцы
Выручка по месяцам
Продажи по регионам — таблица
```

После добавления проверьте содержимое каждого блока.

### Общая прибыль

```text
1530.00
```

### Выручка по регионам — столбцы

```text
Север = 1360.00
Юг    = 2645.00
```

### Выручка по месяцам

```text
2026-01 = 1160.00
2026-02 = 1180.00
2026-03 = 1665.00
```

### Продажи по регионам — таблица

| region | SUM(revenue) | Прибыль |
|---|---:|---:|
| Север | 1360.00 | 520.00 |
| Юг | 2645.00 | 1010.00 |

Если значение внутри Chart неверно, исправляйте сам Chart через Explore. Перемещение или изменение размера блока на Dashboard расчёт не меняет.

## Раскладываем блоки

Для учебного Dashboard используйте структуру:

```text
┌───────────────────────────────────────┐
│ Общая прибыль                         │
├───────────────────┬───────────────────┤
│ Выручка           │ Выручка           │
│ по регионам       │ по месяцам        │
├───────────────────┴───────────────────┤
│ Продажи по регионам — таблица         │
└───────────────────────────────────────┘
```

Перетаскивайте Chart по сетке Dashboard.

Размер блока меняется перетаскиванием его границы или угла.

Разместите:

```text
верх:  Общая прибыль
центр: Выручка по регионам — столбцы | Выручка по месяцам
низ:   Продажи по регионам — таблица
```

## Сохраняем Dashboard

Нажмите:

```text
Save
```

Сохранение фиксирует заголовок, состав Chart, расположение и размеры блоков.

Обновите страницу браузера и проверьте, что раскладка сохранилась.

## Draft и Published

Новый Dashboard имеет статус:

```text
Draft
```

После проверки нажмите на `Draft`.

Статус должен измениться на:

```text
Published
```

`Published` — статус Dashboard внутри Superset. Он не делает Dashboard общедоступным в Интернете и не отменяет права доступа к данным.

Оставьте Dashboard в состоянии `Published`.

## Проверяем список Dashboards

Откройте:

```text
Dashboards
```

Найдите:

```text
Учебные продажи
```

Нажмите его имя.

Откроется сохранённый Dashboard в режиме просмотра.

Проверьте четыре Chart и их контрольные значения.

## Повторно редактируем Dashboard

Нажмите:

```text
Edit dashboard
```

Измените размер одного блока, например `Выручка по месяцам`.

Нажмите:

```text
Save
```

Вернитесь в `Dashboards`, снова откройте `Учебные продажи` и проверьте сохранённую раскладку.

## Что хранит Dashboard

В рамках этого курса разделение такое:

```text
Chart
→ запрос, Metric, Dimensions, Filters, тип визуализации

Dashboard
→ состав Chart, их расположение, размеры и настройки панели
```

Изменение размера блока не меняет `SUM(revenue)` или `Прибыль`.

## Типовые ошибки

### В панели Charts нет нужного Chart

Проверьте раздел:

```text
Charts
```

Все четыре объекта должны быть сохранены в уроке 07.

### После перезагрузки вернулась старая раскладка

После изменения layout требуется:

```text
Save
```

### Dashboard остаётся Draft

Нажмите статус:

```text
Draft
```

и проверьте переход в:

```text
Published
```

### На Dashboard неверные числа

Откройте соответствующий Chart из раздела `Charts` и проверьте его конфигурацию в Explore.

## Критерий завершения

Должно выполняться:

```text
Dashboard = Учебные продажи
Status    = Published
Charts    = 4
```

и сохраняться после повторного открытия:

```text
заголовок
состав Chart
расположение блоков
размеры блоков
```
