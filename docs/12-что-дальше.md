# 12. Что изучать дальше

**Статус:** зафиксирован план урока.

## Что научимся делать

Понимать границу базового навыка и выбирать следующий уровень обучения без перегруза новичка.

## Проверяем, что уже умеем

К этому моменту ученик должен самостоятельно пройти цепочку:

```text
PostgreSQL
→ Dataset
→ Explore
→ Metric
→ Chart
→ Dashboard
→ Native Filters
→ SQL Lab
→ Virtual Dataset
```

## Следующие направления

После базового курса можно отдельно изучать:

- правильную модель аналитических данных;
- более сложный SQL;
- права, роли и `Row Level Security`;
- администрирование Superset;
- резервное копирование и обновление;
- кэширование и фоновые задачи;
- Alerts & Reports;
- API и embedding;
- расширенные визуализации.

## Главное правило

Ни одна из этих тем не добавляется внутрь базового курса задним числом, если без неё новичок уже может выполнить основной рабочий сценарий.

## Практический результат

Ученик понимает, что базовый курс завершён, и может выбрать следующий самостоятельный трек.
