# 12. Что изучать дальше и итоговая проверка

**Статус:** зафиксирован план урока.

## Что научимся делать

Проверять, что базовый навык действительно получен, и выбирать следующий уровень обучения без перегруза.

## Итоговая самостоятельная работа

Без пошаговой инструкции ученик должен на чистом учебном стенде самостоятельно:

1. убедиться, что `training.sales` доступна;
2. подключить PostgreSQL к Superset;
3. создать Dataset;
4. получить в Explore выручку по регионам за выбранный период;
5. создать и сохранить простую Metric;
6. создать простой Calculated Column и использовать его в Explore;
7. построить минимум два Chart;
8. собрать Dashboard;
9. добавить фильтр периода и региона;
10. выполнить эквивалентный простой запрос в SQL Lab;
11. сохранить понятный SQL как Virtual Dataset и построить на нём Chart.

Если ученик не может выполнить один из пунктов без возврата к пошаговой инструкции, соответствующий урок первой версии ещё не считается достаточно понятным.

## Проверяем, что уже умеем

К этому моменту ученик должен понимать цепочку:

```text
PostgreSQL
→ Dataset
→ Explore
→ Metric / Calculated Column
→ Chart
→ Dashboard
→ Native Filters
→ SQL Lab
→ Virtual Dataset
```

## Следующие направления

После базового курса можно отдельно изучать:

- правильную модель аналитических данных;
- более сложный SQL;
- права, роли и `Row Level Security`;
- администрирование Superset;
- резервное копирование и обновление;
- кэширование и фоновые задачи;
- Alerts & Reports;
- API и embedding;
- расширенные визуализации.

## Главное правило

Ни одна из этих тем не добавляется внутрь базового курса задним числом, если без неё новичок уже может выполнить основной рабочий сценарий.
