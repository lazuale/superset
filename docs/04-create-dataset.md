# 04. Создаём первый Dataset

**Статус:** зафиксирован план урока.

## Что научимся делать

Создавать `Dataset` на основе обычной таблицы PostgreSQL, проверять его столбцы и возвращаться к нему для дальнейшей работы.

## В урок входит

- что такое `Dataset` на пальцах;
- выбор подключённой базы;
- выбор схемы `training`;
- выбор таблицы `sales`;
- создание Dataset;
- просмотр столбцов;
- где видеть типы данных;
- проверка, что поле даты можно использовать как временной столбец;
- минимальная правка настроек столбца только если она реально нужна для следующих уроков;
- сохранение изменений;
- выход из Dataset и поиск созданного Dataset в общем списке;
- повторное открытие Dataset;
- изменение одного безопасного параметра и повторное сохранение;
- почему Dataset не является копией строк из PostgreSQL.

## После урока ученик должен уметь

Создать Dataset из существующей таблицы, найти его позже в Superset, снова открыть, проверить или изменить настройки и перейти в `Explore`.

## В урок не входит

Virtual Dataset, сложная модель данных, сертификация Dataset и глубокая настройка metadata.

## Практический результат

Создан и повторно открыт Dataset на таблице `training.sales`, его можно использовать в `Explore`, а поле даты готово для временного анализа.
