# 04. Создаём первый Dataset

**Статус:** зафиксирован план урока.

## Что научимся делать

Создавать `Dataset` на основе обычной таблицы PostgreSQL и проверять, что столбцы распознаны пригодно для дальнейшего анализа.

## В урок входит

- что такое `Dataset` на пальцах;
- выбор подключённой базы;
- выбор схемы `training`;
- выбор таблицы `sales`;
- создание Dataset;
- просмотр столбцов;
- где видеть типы данных;
- проверка, что поле даты можно использовать как временной столбец;
- минимальная правка настроек столбца только если она реально нужна для следующих уроков;
- почему Dataset не является копией строк из PostgreSQL.

## После урока ученик должен уметь

Создать Dataset из существующей таблицы, проверить его столбцы и открыть Dataset для анализа.

## В урок не входит

Virtual Dataset, сложная модель данных, сертификация Dataset и глубокая настройка metadata.

## Практический результат

Создан Dataset на таблице `training.sales`, его можно открыть в `Explore`, а поле даты готово для временного анализа.
