# 09. Добавляем фильтры Dashboard

**Статус:** зафиксирован план урока.

## Что научимся делать

Добавлять `Native Filters` и понимать, на какие графики они действуют.

## В урок входит

- фильтр периода;
- фильтр региона;
- фильтр менеджера;
- выбор Dataset и поля;
- `Scope` фильтра;
- применение фильтра к нескольким Chart;
- проверка изменения результата.

## После урока ученик должен уметь

Добавить фильтры на Dashboard и осознанно определить область их действия.

## В урок не входит

Сложные зависимости фильтров, cross-filtering, drill-функции и dashboard-level security.

## Практический результат

Dashboard можно интерактивно фильтровать по периоду, региону и менеджеру.
