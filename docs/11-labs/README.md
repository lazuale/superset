# Практикум

`11-labs` — единственное каноническое место для исполняемых сценариев, fixtures, reset и expected results.

## Правила

Каждый stateful lab должен иметь:

- известное исходное состояние;
- зафиксированные версии;
- команды запуска;
- проверку результата;
- reset/rebuild;
- повторный прогон, если заявлена детерминированность.

Draft lab со статусом `Проверка на стенде: не выполнена` не считается готовым к merge.

## Stage 0

1. [`00-sandbox/`](00-sandbox/README.md) — Superset 6.1.0;
2. [`01-training-database/`](01-training-database/README.md) — отдельная PostgreSQL analytics database и детерминированный small fixture.

Дальнейшие каталоги создаются только вместе с соответствующими учебными этапами.
