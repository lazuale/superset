# Шпаргалка к уроку 06. SUM, COUNT, COUNT DISTINCT, AVG, MIN и MAX

Эта памятка нужна, когда колонка выбрана правильно, но непонятно, **как именно её считать**.

Главная мысль:

> одна и та же колонка с разным агрегированием отвечает на разные вопросы.

## Самая короткая таблица

| Нужно узнать | Использовать |
|---|---|
| сумму значений | `SUM` |
| количество строк | `COUNT(*)` |
| количество непустых значений | `COUNT(column)` |
| количество уникальных значений | `COUNT_DISTINCT(column)` |
| среднее | `AVG` |
| минимум | `MIN` |
| максимум | `MAX` |

## 1. `SUM` — сложить значения

Примеры:

```text
SUM(revenue)
SUM(cost)
SUM(quantity)
```

Для `training.sales`:

```text
SUM(revenue)  = 4005.00
SUM(quantity) = 31
```

Но не каждое числовое поле можно складывать.

Осторожно с такими значениями:

```text
процент
температура
средняя скорость
тариф
остаток на дату
```

Числовой тип ещё не означает, что `SUM` имеет бизнес-смысл.

## 2. `COUNT(*)` — посчитать строки

```text
COUNT(*) = количество строк после фильтрации
```

В учебном Dataset:

```text
COUNT(*) = 12
```

Это можно назвать «12 продаж» только потому, что зерно учебного Dataset:

```text
1 строка = 1 продажа
```

Если одна строка = позиция документа, `COUNT(*)` считает позиции, а не документы.

→ [Зерно Dataset](06c-data-grain.md)

## 3. `COUNT(column)` — посчитать непустые значения

`COUNT(column)` не считает `NULL`.

В учебных данных:

```text
COUNT(*)       = 12
COUNT(manager) = 11
```

Одна строка имеет:

```text
manager = NULL
```

Поэтому результаты различаются.

## 4. `COUNT_DISTINCT` — посчитать разные объекты

В учебном Dataset:

```text
COUNT(manager)          = 11
COUNT_DISTINCT(manager) = 4
```

Используйте `COUNT_DISTINCT`, если один объект может повторяться в нескольких строках и вопрос звучит:

```text
сколько разных сотрудников?
сколько автомобилей?
сколько документов?
сколько клиентов?
```

Классическая ошибка:

```text
COUNT(*)
→ строки

COUNT_DISTINCT(vehicle_id)
→ уникальные автомобили
```

## 5. `AVG` — среднее исходных наблюдений

В учебных данных:

```text
AVG(revenue) = 333.75
```

Потому что:

```text
4005 / 12 = 333.75
```

Осторожно со средним от уже рассчитанных средних.

Пример:

```text
Группа A: 100 операций, AVG = 10
Группа B:   2 операции, AVG = 100
```

Простое:

```text
(10 + 100) / 2
```

не является средним всех 102 операций.

Если средние получены на разном числе наблюдений, нужны исходные строки или корректные веса.

## 6. `MIN` и `MAX`

```text
MIN(value)
→ минимальное значение группы

MAX(value)
→ максимальное значение группы
```

Для дат:

```text
MIN(date)
→ самая ранняя дата

MAX(date)
→ самая поздняя дата
```

Но `MAX(date)` не означает автоматически «взять всю последнюю строку». Для последней записи целиком может понадобиться отдельный SQL.

## 7. Измерение меняет группы, а не формулу метрики

Без измерения (`Dimension`):

```text
SUM(revenue) = 4005.00
```

С:

```text
Dimension = region
```

получаем:

```text
Север = 1360.00
Юг    = 2645.00
```

Формула `SUM(revenue)` та же. Изменились группы, внутри которых она считается.

## 8. Сначала определите объект подсчёта

Перед `COUNT` спросите:

```text
Что я хочу посчитать?
строки?
документы?
автомобили?
сотрудников?
смены?
```

Затем найдите идентификатор этого объекта и проверьте, может ли он повторяться.

## 9. Красный флаг: число выглядит правдоподобно

Самая опасная BI-ошибка — не ошибка SQL, а нормальное на вид неправильное число.

Например:

```text
COUNT(*) = 1200
```

может выглядеть как «1200 автомобилей», хотя это 1200 строк по 137 автомобилям.

Поэтому всегда проговаривайте смысл метрики словами.

## Контрольные значения курса

| Расчёт | Результат |
|---|---:|
| `SUM(revenue)` | 4005.00 |
| `SUM(quantity)` | 31 |
| `COUNT(*)` | 12 |
| `COUNT(manager)` | 11 |
| `COUNT_DISTINCT(manager)` | 4 |
| `COUNT_DISTINCT(office)` | 4 |
| `AVG(revenue)` | 333.75 |
| `AVG(cost)` | 206.25 |

## Главное

```text
SUM              → сумма
COUNT(*)         → строки
COUNT(column)    → непустые значения
COUNT_DISTINCT   → уникальные значения
AVG              → среднее
MIN / MAX        → крайние значения
```

Но сначала:

```text
что означает одна строка Dataset?
```
