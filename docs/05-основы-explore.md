# 05. Осваиваем Explore

**Статус:** зафиксирован план урока.

## Что научимся делать

Получать первый осмысленный аналитический результат через `Explore`.

## В урок входит

- что такое `Explore`;
- выбор столбцов;
- `Group By`;
- простая метрика;
- фильтры;
- `Time Range`;
- сортировка;
- ограничение числа строк;
- запуск запроса;
- чтение результата.

## После урока ученик должен уметь

Ответить через Explore на простой вопрос вроде: «какая выручка по регионам за выбранный период?»

## В урок не входит

Полный каталог настроек Explore, сложные временные функции, Jinja и расширенная аналитика.

## Практический результат

Получена первая агрегированная таблица по учебным продажам.
