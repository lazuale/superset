# 11. Создаём Virtual Dataset

**Статус:** зафиксирован план урока.

## Что научимся делать

Превращать понятный SQL-запрос в `Virtual Dataset` и дальше работать с ним как с обычным источником для Explore.

## В урок входит

- зачем нужен Virtual Dataset;
- простой SQL на учебной таблице;
- сохранение результата как Virtual Dataset;
- открытие Virtual Dataset в Explore;
- построение Chart;
- простое объяснение, когда Virtual Dataset удобен;
- простое объяснение, когда лучше изменить представление или модель в самой базе.

## После урока ученик должен уметь

Создать Virtual Dataset из собственного SQL и использовать его для визуализации.

## В урок не входит

Сложные JOIN/CTE, Jinja, SQL templating, производительность больших Virtual Dataset и архитектура хранилища данных.

## Практический результат

Создан Virtual Dataset и минимум один Chart на его основе.
