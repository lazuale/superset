# 10. SQL Lab с нуля

**Статус:** зафиксирован план урока.

## Что научимся делать

Выполнять простые SQL-запросы в `SQL Lab`, даже если до курса ученик SQL не знал.

## В урок входит

Только необходимый минимум:

- `SELECT`;
- `FROM`;
- `WHERE`;
- `GROUP BY`;
- `ORDER BY`;
- `LIMIT`;
- `SUM` и `COUNT`;
- выбор базы и схемы в SQL Lab;
- выполнение запроса;
- чтение результата;
- сравнение результата SQL с тем, что ранее получали через Explore.

## После урока ученик должен уметь

Самостоятельно написать простой запрос к `training.sales` и получить агрегированный результат.

## В урок не входит

Полный курс SQL, JOIN, оконные функции, CTE, оптимизация запросов и администрирование PostgreSQL.

## Практический результат

Ученик написал и выполнил несколько собственных SQL-запросов в SQL Lab.
