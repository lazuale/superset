# 02. Запускаем учебный Superset

**Статус:** зафиксирован план урока.

## Что научимся делать

Запускать и останавливать готовый учебный стенд Apache Superset 6.1.0 и возвращать его в исходное состояние.

## В урок входит

- основной учебный путь через `docker compose` на Windows, macOS и Linux;
- минимальная подготовка Docker для каждой из трёх систем без отдельного курса по Docker;
- один готовый учебный stack, в который уже входят Superset 6.1.0 и PostgreSQL;
- отдельная установка PostgreSQL учеником не требуется;
- готовые команды первого запуска;
- создание схемы и таблицы `training.sales` внутри учебного PostgreSQL;
- загрузка фиксированных учебных данных из каталога `training/`;
- контрольная проверка данных;
- как понять, что контейнеры запустились;
- как открыть Superset в браузере;
- как войти в учебную учётную запись;
- короткая ориентация: где находятся Datasets, Charts, Dashboards и SQL Lab;
- как остановить стенд;
- как снова его запустить;
- одна простая процедура полного сброса учебного стенда и данных, если ученик что-то сломал.

## После урока ученик должен уметь

Самостоятельно открыть рабочий интерфейс Superset, убедиться, что `training.sales` существует, вернуться к стенду после перезапуска компьютера и при необходимости восстановить чистое учебное состояние.

## В урок не входит

Изучение Docker как отдельной технологии, устройство контейнеров, production deployment, reverse proxy, Redis, Celery и администрирование PostgreSQL.

## Практический результат

В браузере открывается рабочий Superset 6.1.0, а внутри учебного PostgreSQL существует проверенная таблица `training.sales`.
