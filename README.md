# Apache Superset 6.1.0 — вики для новичка

Практический курс для человека, который раньше не работал с Apache Superset.

Цель первой версии: пройти уроки по порядку и самостоятельно освоить базовый рабочий сценарий — от запуска учебного стенда до Dashboard и Virtual Dataset.

## Для кого курс

Курс подходит, если вы:

- раньше не использовали Superset;
- можете не знать SQL;
- не программируете;
- не хотите сначала изучать Docker, PostgreSQL или внутреннюю архитектуру Superset;
- хотите получить базовый навык работы с продуктом на практике.

## Что понадобится

- обычный компьютер с Windows, macOS или Linux;
- возможность установить Docker с поддержкой `docker compose`;
- браузер;
- доступ к GitHub для скачивания файлов курса.

Отдельно устанавливать PostgreSQL не нужно: учебный PostgreSQL входит в готовый стенд курса.

На Windows учебный путь — **Docker Desktop + WSL 2 + Linux-контейнеры**. Все команды терминала из курса выполняйте в оболочке WSL 2. PowerShell и CMD не являются учебным терминалом этого маршрута: так одни и те же команды воспроизводимо работают на Windows, macOS и Linux.

## Получаем файлы курса

Если Git уже установлен:

```bash
git clone https://github.com/lazuale/superset.git
cd superset
```

Если Git не установлен, на странице репозитория GitHub выберите:

```text
Code → Download ZIP
```

Распакуйте архив и откройте терминал в корневом каталоге репозитория — там, где находятся `README.md`, `docs/` и `training/`.

Во всех уроках команды `docker compose ...` выполняются из каталога:

```text
training/
```

если в конкретном шаге явно не сказано иначе.

## Чему научитесь

После курса вы сможете:

1. запустить учебный Superset;
2. проверить учебные данные `training.sales`;
3. подключить PostgreSQL к Superset;
4. создать `Dataset`;
5. работать в `Explore`;
6. создавать простые `Metric` и `Calculated Column`;
7. строить и изменять `Chart`;
8. собирать и изменять `Dashboard`;
9. использовать `Native Filters`;
10. выполнять простые запросы в `SQL Lab`;
11. создавать `Virtual Dataset`.

## Язык курса

Основной язык документации — русский.

Английский текст сохраняется, когда читателю важно увидеть именно официальное название сущности, экрана, поля, кнопки или другого элемента Superset, а также в SQL, коде, командах, именах файлов и технических идентификаторах.

Правило простое:

```text
официальное имя в интерфейсе или коде
→ оставляем как есть

обычное авторское объяснение
→ пишем по-русски
```

Например, название колонки `Is temporal` остаётся английским, потому что именно такой текст нужно найти в интерфейсе. Но в пояснении используется выражение «временной столбец», а не «temporal-столбец».

При первом появлении важный термин объясняется по-русски.

## Как читать контрольные числа

В уроках приводятся **точные числовые значения**, по которым проверяется правильность расчёта.

Например:

```text
Север = 1360.00
Прибыль = 1530.00
```

Superset 6.1.0 по умолчанию может применять к метрике (`Metric`) адаптивное отображение чисел. Поэтому то же значение на графике (`Chart`) может визуально выглядеть, например, так:

```text
1360   → 1.36k
1530   → 1.53k
```

Это не расхождение в расчёте: меняется только представление числа.

В базовом маршруте форматирование специально не настраивается, чтобы не смешивать расчёт и оформление. Если нужно управлять видом чисел, процентов и дат, после урока 07 используйте отдельный [справочник по форматированию](docs/07c-formatting.md).

## Как устроены дополнительные материалы

У курса два типа дополнительных страниц.

### Шпаргалка

Короткая памятка к уже изученной теме:

```text

→ короткий алгоритм
→ контрольный пример
```

Она не должна заменять урок и не должна заранее вводить большой новый блок функций.

### Справочник

Более подробный необязательный материал. Он может вводить следующую возможность после соответствующей практики:

```text

не требуется проходить для завершения базового маршрута
```

Это разделение сделано специально, чтобы основной курс оставался линейным.

## Учебные данные

Весь базовый курс использует одну небольшую таблицу продаж:

```text
training.sales
```

Поля специально подобраны так, чтобы на них было удобно изучать группировки, фильтры, периоды, метрики и графики: дата продажи, регион, офис, менеджер, продукт, количество, выручка и себестоимость.

Файлы учебного стенда и данных находятся в каталоге [`training/`](training/README.md).

## Когда базовый курс считается пройденным

В последнем уроке нужно без пошаговой подсказки самостоятельно выполнить цепочку:

```text
запустить стенд
   ↓
проверить training.sales
   ↓
подключить PostgreSQL
   ↓
создать Dataset
   ↓
получить результат в Explore
   ↓
создать Calculated Column
   ↓
создать Metric
   ↓
построить базовые графики (Chart)
   ↓
собрать Dashboard
   ↓
добавить Native Filters и проверить Scoping
   ↓
выполнить запрос в SQL Lab
   ↓
создать Virtual Dataset
```

Финальный урок проверяет `Table`, `Big Number`, `Bar Chart`, `Line Chart`, обычный фильтр Explore, временную группировку и настройку `Scoping` для части графиков. Если весь набор выполняется самостоятельно и контрольные значения совпадают — базовый навык работы с Superset получен.
