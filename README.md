# Apache Superset 6.1.0 — вики для новичка

Эта вики нужна для одной задачи: **человек, который раньше не работал с Apache Superset, должен пройти курс по порядку и самостоятельно получить базовые рабочие навыки**.

Не справочник администратора. Не энциклопедия всех возможностей. Не архитектурный трактат.

## Что должен уметь человек после курса

После прохождения 12 уроков ученик должен уметь без посторонней помощи:

1. запустить учебный Superset;
2. подключить PostgreSQL;
3. создать набор данных — `Dataset`;
4. работать в `Explore`;
5. создавать простые метрики — `Metric`;
6. использовать вычисляемые столбцы — `Calculated Column`;
7. строить основные графики — `Chart`;
8. собрать панель — `Dashboard`;
9. добавить фильтры панели — `Native Filters`;
10. выполнить простой запрос в `SQL Lab`;
11. создать виртуальный набор данных — `Virtual Dataset`;
12. понимать, что изучать следующим уровнем.

Если тема не помогает получить один из этих навыков, **в первую версию курса она не входит**.

## Для кого курс

Курс рассчитан на человека, который:

- Superset раньше не использовал;
- может не знать SQL;
- не обязан уметь программировать;
- не обязан понимать Docker, Redis, Celery, Flask или внутреннее устройство Superset;
- хочет сначала научиться пользоваться продуктом, а уже потом разбираться глубже.

## Язык

Объяснения, заголовки и инструкции пишутся **по-русски**.

Английский используется только там, где это официальное название сущности или элемента интерфейса Superset: `Dataset`, `Explore`, `Metric`, `Chart`, `Dashboard`, `SQL Lab`, `Native Filters`, `Virtual Dataset` и т. п.

При первом появлении термин обязательно объясняется по-русски.

## Как пишется каждый урок

Каждый урок отвечает на один практический вопрос и строится одинаково:

```text
Что научимся делать
Что нужно до начала
На пальцах: что это такое
Делаем по шагам
Что должно получиться
Что произошло внутри Superset
Попробуй сам
Если не получилось
Следующий урок
Официальные источники
```

Главное правило: **сначала действие и навык, потом объяснение внутренней механики**.

Практика находится прямо внутри урока. Не нужно прыгать между отдельными «теорией», «лабораторной», «справочником» и «методологией».

## Учебные данные

Весь курс использует одну простую таблицу продаж `training.sales`.

В ней будут понятные поля: дата продажи, регион, офис, менеджер, продукт, количество, выручка и себестоимость. Данные маленькие, чтобы итог можно было проверить вручную.

Контракт учебных данных зафиксирован в [учебные-данные/README.md](учебные-данные/README.md).

## Что намеренно не входит в первую версию

До завершения базового курса не добавляем отдельные главы про:

- внутреннюю серверную архитектуру Superset;
- Redis и Celery;
- Kubernetes;
- production-развёртывание;
- глубокую настройку ролей и RLS;
- API, MCP и embedding;
- разработку расширений;
- полный каталог драйверов;
- полный каталог визуализаций;
- полный справочник настроек;
- отдельную систему meta-документации;
- отдельный evidence ledger;
- отдельную архитектуру лабораторных работ.

Эти темы могут появиться **только после** того, как базовая вики действительно научит новичка пользоваться Superset.

## Версия

Курс пишется для **Apache Superset 6.1.0**. Технические утверждения проверяются по официальным материалам Apache Superset. В каждом готовом уроке внизу указываются конкретные официальные источники.

## Критерий готовности первой версии

Первая версия считается готовой только тогда, когда новичок может пройти уроки 1–12 по порядку и в конце самостоятельно:

```text
PostgreSQL
   ↓
Dataset
   ↓
Explore
   ↓
Metric
   ↓
Chart
   ↓
Dashboard
   ↓
Native Filters
   ↓
SQL Lab
   ↓
Virtual Dataset
```

До достижения этого результата структуру курса не усложняем.
