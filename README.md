# Apache Superset 6.1.0 — вики для новичка

Практический курс для человека, который раньше не работал с Apache Superset.

Цель первой версии простая: пройти уроки по порядку и самостоятельно освоить базовый рабочий сценарий — от запуска учебного стенда до Dashboard и Virtual Dataset.

## Для кого курс

Курс подходит, если вы:

- раньше не использовали Superset;
- можете не знать SQL;
- не программируете;
- не хотите сначала изучать Docker, PostgreSQL или внутреннюю архитектуру Superset;
- хотите получить базовый навык работы с продуктом на практике.

## Что понадобится

- обычный компьютер с Windows, macOS или Linux;
- возможность установить Docker с поддержкой `docker compose`;
- браузер;
- доступ к GitHub для скачивания файлов курса.

Отдельно устанавливать PostgreSQL не нужно: учебный PostgreSQL входит в готовый стенд курса.

На Windows учебный путь — **Docker Desktop + WSL 2 + Linux containers**. Все команды терминала из курса выполняйте в оболочке WSL 2. PowerShell и CMD не являются учебным терминалом этого маршрута: так одни и те же команды воспроизводимо работают на Windows, macOS и Linux.

## Получаем файлы курса

Перед началом нужна локальная копия этого репозитория.

Если Git уже установлен, в терминале выполните:

```bash
git clone https://github.com/lazuale/superset.git
cd superset
```

Если Git не установлен, на странице репозитория GitHub выберите:

```text
Code → Download ZIP
```

Распакуйте архив и откройте терминал в корневом каталоге распакованного репозитория — там, где находятся `README.md`, `docs/` и `training/`.

Во всех уроках команды `docker compose ...` выполняются из каталога:

```text
training/
```

если в конкретном шаге явно не сказано иначе.

## Чему научитесь

После курса вы сможете:

1. запустить учебный Superset;
2. проверить учебные данные `training.sales`;
3. подключить PostgreSQL к Superset;
4. создать `Dataset`;
5. работать в `Explore`;
6. создавать простые `Metric` и `Calculated Column`;
7. строить и изменять `Chart`;
8. собирать и изменять `Dashboard`;
9. использовать `Native Filters`;
10. выполнять простые запросы в `SQL Lab`;
11. создавать `Virtual Dataset`.

Английские названия оставляются там, где это официальные названия сущностей, экранов и элементов интерфейса Superset. При первом появлении термин объясняется по-русски.

## Учебные данные

Весь базовый курс использует одну небольшую таблицу продаж:

```text
training.sales
```

Поля специально подобраны так, чтобы на них было удобно изучать группировки, фильтры, периоды, метрики и графики: дата продажи, регион, офис, менеджер, продукт, количество, выручка и себестоимость.

Файлы учебного стенда и данных находятся в каталоге [`training/`](training/README.md).

## Версия курса

Курс зафиксирован для **Apache Superset 6.1.0**. Инструкции v1 должны соответствовать этой версии и сверяться с официальной документацией и исходным кодом Apache Superset 6.1.0.
