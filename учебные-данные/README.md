# Учебные данные

Вся первая версия курса использует **один небольшой и понятный набор данных**.

## Таблица

```text
training.sales
```

## Поля

| Поле | Что означает |
|---|---|
| `sale_id` | номер строки продажи |
| `sale_date` | дата продажи |
| `region` | регион |
| `office` | офис |
| `manager` | менеджер |
| `product` | продукт |
| `quantity` | количество |
| `revenue` | выручка |
| `cost` | себестоимость |

## Требования к данным

Данные должны быть маленькими и понятными без дополнительной предметной области:

- несколько дат;
- несколько регионов;
- несколько офисов;
- несколько менеджеров;
- несколько продуктов;
- повторяющиеся значения для группировки;
- числа, удобные для ручной проверки `SUM`, `COUNT`, `AVG`;
- никаких искусственных сложностей, которые не нужны для базового курса.

## Файлы, которые появятся при написании практики

```text
учебные-данные/
├── README.md
├── схема.sql
├── данные.sql
└── проверка.sql
```

`схема.sql` создаёт таблицу.

`данные.sql` загружает фиксированный набор строк.

`проверка.sql` содержит контрольные запросы и ожидаемые итоги для сверки с Superset.

До написания соответствующего урока пустые SQL-файлы не создаются.
